Use sonner for toast notifications. Mount `Toaster` once in the root layout, then call `toast` from
`svelte-sonner` anywhere. Theme follows [mode-watcher](https://www.shadcn-svelte.com/docs/components/sonner);
icons come from lucide.

```svelte
<script lang="ts">
	import { toast } from 'svelte-sonner';
	import { Toaster } from '$lib/components/ui/sonner/index.js';
	import Button from '$lib/components/ui/button.svelte';
</script>

<Toaster />
<Button onclick={() => toast('Hello world')}>Show toast</Button>
```
