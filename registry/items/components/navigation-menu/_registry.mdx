Use navigation-menu for site nav with dropdown panels. Compose `List` / `Item` with `Trigger` +
`Content` menus, and `Link` for direct destinations. Import `navigationMenuTriggerStyle` for link
items that match trigger chrome.

```svelte
<script lang="ts">
	import * as NavigationMenu from '$lib/components/ui/navigation-menu/index.js';
</script>

<NavigationMenu.Root>
	<NavigationMenu.List>
		<NavigationMenu.Item>
			<NavigationMenu.Trigger>Item One</NavigationMenu.Trigger>
			<NavigationMenu.Content>
				<NavigationMenu.Link href="#/">Link</NavigationMenu.Link>
			</NavigationMenu.Content>
		</NavigationMenu.Item>
	</NavigationMenu.List>
</NavigationMenu.Root>
```
