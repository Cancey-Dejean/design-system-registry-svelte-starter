Use text for paragraphs, captions, and inline copy. It renders a `p` by default, and `as` switches
the element without changing the typographic styling.

```svelte
<script lang="ts">
	import Text from '$lib/components/ui/text.svelte';
</script>

<Text size="lg">The quick brown fox jumps over the lazy dog.</Text>
<Text as="span" size="sm" tone="muted">Last updated 2 hours ago</Text>
```
