Use range calendar for start–end date selection. Bind `value` as `{ start, end }`. Switch
`captionLayout` between `label`, `dropdown`, `dropdown-months`, and `dropdown-years`.

```svelte
<script lang="ts">
	import { getLocalTimeZone, today } from '@internationalized/date';
	import { RangeCalendar } from '$lib/components/ui/range-calendar/index.js';

	const start = today(getLocalTimeZone());
	let value = $state({
		start,
		end: start.add({ days: 7 })
	});
</script>

<RangeCalendar bind:value class="rounded-md border shadow-sm" />
```
