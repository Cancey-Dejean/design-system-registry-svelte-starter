Use kbd to show keyboard shortcuts. Compose keys with `Kbd.Group` and nest `Kbd.Root` for each key.

```svelte
<script lang="ts">
	import * as Kbd from '$lib/components/ui/kbd/index.js';
</script>

<Kbd.Group>
	<Kbd.Root>Ctrl</Kbd.Root>
	<span>+</span>
	<Kbd.Root>B</Kbd.Root>
</Kbd.Group>
```
