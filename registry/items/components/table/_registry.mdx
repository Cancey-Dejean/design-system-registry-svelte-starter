Use table primitives for structured tabular data. Compose with TanStack Table for full data-grid features
(see the **data-table** guide item).

```svelte
<script lang="ts">
	import * as Table from '$lib/components/ui/table/index.js';
</script>

<Table.Root>
	<Table.Header>
		<Table.Row>
			<Table.Head>Invoice</Table.Head>
			<Table.Head>Status</Table.Head>
			<Table.Head class="text-end">Amount</Table.Head>
		</Table.Row>
	</Table.Header>
	<Table.Body>
		<Table.Row>
			<Table.Cell>INV001</Table.Cell>
			<Table.Cell>Paid</Table.Cell>
			<Table.Cell class="text-end">$250.00</Table.Cell>
		</Table.Row>
	</Table.Body>
</Table.Root>
```
