Use item for flexible content rows with title, description, media, and actions. Group rows with
`Item.Group` and `Item.Separator`. Render as a link via the `child` snippet. Set `variant` and `size`
on `Item.Root`.

```svelte
<script lang="ts">
	import * as Item from '$lib/components/ui/item/index.js';
	import { Button } from '$lib/components/ui/button/index.js';
</script>

<Item.Root variant="outline">
	<Item.Content>
		<Item.Title>Basic Item</Item.Title>
		<Item.Description>A simple item with title and description.</Item.Description>
	</Item.Content>
	<Item.Actions>
		<Button variant="outline" size="sm">Action</Button>
	</Item.Actions>
</Item.Root>
```
