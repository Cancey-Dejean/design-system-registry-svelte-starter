Pick `level` for document semantics and `size` for the visual scale, so a page can keep a single `h1`
without being locked into the largest type size.

```svelte
<script lang="ts">
	import Heading from '$lib/components/ui/heading.svelte';
</script>

<Heading level={1} size="2xl">Design system</Heading>
<Heading level={2} size="md" tone="muted">Components</Heading>
```
