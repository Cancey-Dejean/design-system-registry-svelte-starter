Use the container to constrain page or section content. Set `size` to `base`, `contained`, `design`,
`thin`, or `full`.

```svelte
<script lang="ts">
	import Container from '$lib/components/ui/container.svelte';
</script>

<Container size="base">
	<p>Content goes here...</p>
</Container>
```
