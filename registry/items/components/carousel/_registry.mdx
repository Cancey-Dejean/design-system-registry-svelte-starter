Use carousel for swipeable slides. Compose with `Carousel.Content`, `Carousel.Item`, and optional
`Carousel.Previous` / `Carousel.Next` controls. Pass Embla options through `opts`.

```svelte
<script lang="ts">
	import * as Carousel from '$lib/components/ui/carousel/index.js';
</script>

<Carousel.Root class="w-full max-w-xs">
	<Carousel.Content>
		{#each Array(5) as _, i (i)}
			<Carousel.Item>
				<div class="p-1">Slide {i + 1}</div>
			</Carousel.Item>
		{/each}
	</Carousel.Content>
	<Carousel.Previous />
	<Carousel.Next />
</Carousel.Root>
```
