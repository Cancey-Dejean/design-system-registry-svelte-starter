Use sidebar for app navigation shells. Wrap with `Sidebar.Provider`, compose `Root` + menu parts,
and place page chrome in `Sidebar.Inset`. Requires `$lib/hooks/is-mobile.svelte.js` (IsMobile) and
sidebar CSS variables in your theme.

```svelte
<script lang="ts">
	import * as Sidebar from '$lib/components/ui/sidebar/index.js';
</script>

<Sidebar.Provider>
	<Sidebar.Root>
		<Sidebar.Content>
			<Sidebar.Group />
		</Sidebar.Content>
	</Sidebar.Root>
	<main>
		<Sidebar.Trigger />
	</main>
</Sidebar.Provider>
```
