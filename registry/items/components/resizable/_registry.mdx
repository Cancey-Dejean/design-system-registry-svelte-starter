Use resizable for split layouts. Built on PaneForge. Compose `PaneGroup` + `Pane` + `Handle`. Set
`direction` to `horizontal` or `vertical`. Pass `withHandle` on `Handle` for a visible grip.

```svelte
<script lang="ts">
	import * as Resizable from '$lib/components/ui/resizable/index.js';
</script>

<Resizable.PaneGroup direction="horizontal">
	<Resizable.Pane>One</Resizable.Pane>
	<Resizable.Handle />
	<Resizable.Pane>Two</Resizable.Pane>
</Resizable.PaneGroup>
```
