Use field to wrap form controls with labels, descriptions, and errors. Compose `Field.Group` and
`Field.Set` for multi-field layouts. Set `orientation` to `vertical`, `horizontal`, or `responsive`.

```svelte
<script lang="ts">
	import * as Field from '$lib/components/ui/field/index.js';
	import { Input } from '$lib/components/ui/input/index.js';
</script>

<Field.Group>
	<Field.Field>
		<Field.Label for="username">Username</Field.Label>
		<Input id="username" placeholder="shadcn" />
		<Field.Description>This is your public display name.</Field.Description>
	</Field.Field>
</Field.Group>
```
